⛽ API Harga BBM Pertamina

API statis read-only (JSON) — harga terkini & riwayat per tanggal.

Data diambil dari MyPertamina, dinormalkan, lalu di-hosting sebagai berkas JSON statis di GitHub Pages. Karena melayani header Access-Control-Allow-Origin: *, API ini bisa dipanggil dari domain mana pun (CORS aktif). Diperbarui otomatis via GitHub Actions.

Base URL

./v1/

Semua path di bawah relatif terhadap base URL tersebut.

Endpoint

MetodePath & keteranganCoba

Format umum

  • Satuan harga: IDR/liter (Rupiah per liter).
  • price bertipe angka; null = produk tidak tersedia di provinsi tsb.
  • slug dipakai pada path, mis. prov-dki-jakarta, pertamax. Daftar lengkap: v1/provinsi.json & v1/produk.json.

v1/history/index.json — rentang tanggal & daftar perubahan

Dipakai untuk mengetahui rentang tanggal yang bisa dipanggil (firstDate…lastDate) dan tanggal-tanggal saat harga berubah (snapshotDates). 

{
  "status": "success",
  "source": "https://mypertamina.id/about/product-price",
  "unit": "IDR/liter",
  "note": "Panggil history/{YYYY-MM-DD}.json untuk tanggal mana pun pada rentang firstDate..lastDate ...",
  "firstDate": "2026-09-02",   // tanggal paling awal yang tersedia (= perubahan harga terakhir yang diketahui)
  "lastDate": "2026-11-05",    // tanggal terbaru (hari ini, WIB)
  "totalDays": 65,             // jumlah tanggal yang bisa dipanggil
  "totalSnapshots": 1,         // jumlah titik perubahan harga
  "snapshotDates": [ "2026-09-02" ]   // tanggal-tanggal saat harga berubah
}

v1/history/{YYYY-MM-DD}.json — harga yang berlaku pada tanggal itu

Bisa dipanggil untuk tanggal berapa pun dalam rentang firstDate..lastDate. Harga mengikuti perubahan terakhir pada/sebelum tanggal tsb (carry-forward). v1/history/latest.json = alias tanggal terbaru. 

{
  "status": "success",
  "date": "2026-10-01",          // tanggal yang diminta
  "effectiveDate": "2026-09-02", // perubahan harga terakhir yang berlaku pada "date"
  "capturedAt": "2026-11-05T05:39:02.996Z",
  "unit": "IDR/liter",
  "provinces": [
    { "province": "Prov. DKI Jakarta", "slug": "prov-dki-jakarta",
      "prices": [ { "product": "PERTAMAX", "slug": "pertamax", "price": 15950 } ] }
  ]
}

v1/history/provinsi/{slug}.json — deret waktu satu provinsi

{
  "status": "success",
  "province": "Prov. DKI Jakarta",
  "slug": "prov-dki-jakarta",
  "firstDate": "2026-09-02",
  "lastDate": "2026-11-05",
  "products": [ "DEXLITE", "PERTALITE", "PERTAMAX", "..." ],
  "history": [
    { "date": "2026-09-02", "prices": { "PERTAMAX": 15950, "PERTALITE": 10000 } }
  ]
}

Contoh pemakaian

cURL

curl -s "./v1/provinsi/prov-dki-jakarta.json"

JavaScript (fetch)

const res = await fetch("./v1/nasional.json");
const data = await res.json();
console.log(data.provinces);
Batasan riwayat. Tanggal sebelum firstDate (perubahan harga terakhir yang diketahui dari field updatedDate) atau di masa depan (setelah lastDate) akan mengembalikan 404. API MyPertamina tidak menyediakan harga historis sebelum tanggal itu.
